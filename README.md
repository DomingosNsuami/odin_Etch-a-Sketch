# Etch-a-Sketch (EN)

*[Leia em Português](#etch-a-sketch-pt)*

A browser-based **Etch-a-Sketch** application built as part of **The Odin Project** (Foundations Course). This project focuses on DOM manipulation, Flexbox layouts, and event handling in JavaScript.

## Live Demo
[View Live Project](https://github.io) *(Replace with your GitHub Pages link)*

## Features
- **Dynamic Grid:** Starts with a default 16x16 grid built using Flexbox.
- **Hover Drawing:** Leaves a trail when hovering the mouse over the grid squares.
- **Custom Grid Size:** Allows users to resize the grid (up to 100x100) via a prompt/button while maintaining the total container dimensions.
- **Clear / Reset:** Quickly wipes the board clean to start a new drawing.
- *(Optional - remove if not implemented)* **Color Modes:** Supports classic black, random RGB colors, and progressive darkening.

## Built With
- HTML5
- CSS3 (Flexbox)
- Vanilla JavaScript (ES6+)

## Getting Started
To run this project locally:
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder and open `index.html` in your browser.

# Etch-a-Sketch (PT)

*[Read in English](#etch-a-sketch-en)*

Uma aplicação web do clássico **Etch-a-Sketch** (Lousa Mágica) desenvolvida como parte do currículo **The Odin Project** (Curso Foundations). O foco deste projeto é praticar manipulação do DOM, layouts com Flexbox e eventos em JavaScript.

## Demonstração (Live Demo)
[Ver Projeto Online](https://github.io) *(Substitua pelo seu link do GitHub Pages)*

## Funcionalidades
- **Grade Dinâmica:** Inicia com uma grade padrão de 16x16 construída com Flexbox.
- **Desenho ao Passar o Mouse:** Preenche os quadrados conforme o cursor passa por cima deles.
- **Tamanho Personalizado:** Permite ao usuário alterar a resolução da grade (até 100x100) mantendo o tamanho total do quadro.
- **Limpar / Resetar:** Apaga o desenho atual para começar um novo.
- *(Opcional - remova se não implementou)* **Modos de Cor:** Suporte para cor padrão, cores RGB aleatórias e escurecimento progressivo.

## Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox)
- JavaScript Puro (ES6+)

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` no seu navegador.
